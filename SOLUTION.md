## Решения

Матчи фильтруются по статусу:

- **Все матчи** — отображаются все матчи тура, включая текущие и перенесённые.
- **Предстоящие** — матчи со статусом `scheduled`.
- **Завершённые** — матчи со статусом `finished`.

Матчи со статусами `live` и `postponed` отображаются в общем списке, поскольку они не относятся к предстоящим или завершённым.

Для матчей без даты начала не отображается дата, чтобы избежать некорректного значения. Если счёт отсутствует, вместо него выводится прочерк.

При загрузке данных проверяется успешность HTTP-ответа и наличие массива матчей. При ошибке пользователь видит сообщение и может повторить загрузку.

Избранное хранится в состоянии React по идентификаторам матчей. При изменении списка создаётся новый массив, поэтому React корректно обновляет интерфейс.

## Баги из части 2

1. **Звёздочки.** В `isFavorite` использовался `Boolean(favorites.indexOf(id))`. Метод `indexOf` возвращает `-1`, если элемент не найден, а `0`, если он находится в начале массива. Из-за этого избранное определялось неправильно. Также исходный код изменял массив напрямую и передавал React ту же ссылку. Исправил проверку через `includes` и обновление состояния через создание нового массива.

2. **«Обновлено N сек назад».** Счётчик использовал значение `seconds` из замыкания, из-за чего не увеличивался корректно. Кроме того, интервал не очищался при размонтировании компонента, а переданный проп `since` не использовался. Исправил расчёт времени на основе текущего времени и даты последнего обновления, добавил очистку интервала.
